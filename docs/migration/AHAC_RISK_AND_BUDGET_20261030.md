# AHAC 约束、展开与 Critic 预算修复

## 版本边界

此版保留 DCOL 碰撞损失，但风险反馈改为统一米制净空的 AHAC 派生算法。
它不是原论文接触刚性/Jacobian机制的复现。记录 actor 梯度裁剪比和一步代理速度误差，
用于稳定性门限；它们不能代替 PhysX 接触 Jacobian 或真实梯度误差验证。

旧 `zhang_main_20261029/ahac` 原始73次更新复核：72次约束惩罚为0；其物理步为.01秒、
策略步.1秒，最大实际使用H288，完整日志风险峰值7.9748。用户提供的5.713稀有风险
也作为独立反例固定验证。旧训练/检查点/TensorBoard保留，新AHAC随机初始化。

## 已实现

1. 每条轨迹先取时间峰值，再取最坏轨迹；惩罚、对偶更新、H控制都使用该统计。
   均值仅作日志。初始dual=1，惩罚为 `dual*relu(worst_risk-budget)`，安全时不提供负奖励。
   32×256批次只放一个5.713风险样本时，旧均值低于.1，新惩罚5.613且H32缩至25。
2. 高风险、失败轨迹比例>.05、actor裁剪比>2或模型速度误差>.5m/s时缩短H。
   只有峰值风险<半预算、失败比例≤.05、裁剪比≤1且模型误差≤.5，连续3次更新后才增长4步。
   纯时间截断不计为失败轨迹。最小16、最大300。稳定计数、dual和H均进入版本2检查点。
3. 默认AHAC和SHAC都为per_step；新计划显式指定，不使用有效窗口K缩放。
4. 风险使用静态有验证出口代理、真实长方体/有限圆柱体SDF、无人机球半径.3m、地面、
   中心高度上下界.2/4m的最小净空。动态碰撞终点使用保存的物理子步位置和障碍快照。
   净空以米输入softplus，尺度.05m、危险净空.1m；softplus后的风险和预算为无量纲。
   `radius*(DCOL_alpha-1)`继续用于原碰撞成本，绝不输入AHAC风险。
5. Critic每遍固定4个minibatch，每轮至多64次optimizer.step，与H无关。
   至少一个环境、默认10%环境整段保留验证，和训练环境不重叠。只有单环境单元探针
   才使用不重叠样本替代。验证数据不参与梯度更新；AHAC停止依据独立验证TD均方误差
   的停滞或相对变化，仍受硬预算约束。日志分开记录遍数、优化次数、验证TD误差和样本数。

SHAC/AHAC共同采用：真正终止next value=0；时间截断使用重置前完整Critic状态；
普通时域末端保留冻结Critic对输入的梯度。真正终止与时域末端重合时终止优先。
旧continuing-reset语义及旧AHAC检查点不作为新版算法的续训来源。

## 验证证据

- `tests/test_ahac_stability.py`覆盖单个危险样本、三类不稳定信号、连续稳定增长、状态恢复、
  动态米制净空与DCOL代理数值区分，以及上下高度梯度。
- H16、H288、N256两种批次都恰为64次Critic更新，而不是随H增至1152次。
- 验证环境与训练环境索引不重叠；只修改验证标签不会改变训练后的Critic参数。
- 两种算法均覆盖终止/超时/普通末端及复用done缓冲区的完整runner梯度测试。
- 真实16环境/60动态障碍：SHAC两次更新256转移，2次吸收终止、62次超时；
  AHAC两次更新224转移，2次吸收终止、48次超时。吸收bootstrap绝对值总和均为0，
  速度监督覆盖率均为1，无非有限状态/梯度，每次Critic优化4次（测试限定一遍）。
  AHAC首轮风险峰值8.00034、约束惩罚7.90034，H8缩至6；下一轮风险.0732处于保持带，H保持6。

功能检查含强制事件注入，不计导航成功。完整回归415项和521个子测试通过；原始证据位于
`logs/20hz_default_20261029/`。新五组计划为 `configs/experiments/zhang_20hz_controls.json`。
当前20Hz BPTT基线保持原进程；旧step TensorBoard保留。新SHAC/AHAC必须从最终干净main
启动，并核对20Hz、per_step、上述bootstrap协议及Critic预算，不能复用旧组。
