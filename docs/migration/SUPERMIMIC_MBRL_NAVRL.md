# SuperMimic MBRL 接入 NavRL

状态：**设计方案，尚未实现**。本方案复用现有 NavRL 任务、控制器和训练课程，新增独立的 SuperMimic 训练器。现有 PPO 与 Zhang 入口保持不变。

## 1. 现有任务契约

- 环境：Isaac Lab 3.0.0、PhysX、`NavRLEnv`（`DirectRLEnv`），1024 架无人机共享静态地形和全局动态障碍。
- 动作：目标方向坐标系下的 **3 维目标速度**，范围 `[-2, 2]`；经 `goal_frame` 转到世界系，再由原版 Lee 控制器、RotorGroup 和零延迟 Thruster 执行。
- 观测：202 维，即导航状态 8 维、静态 LiDAR 144 维、最近 5 个动态障碍 50 维。LiDAR 使用原版 `4 - distance` 表示。
- 基础 NavRL：`sim.dt=0.016 s`、`decimation=1`，物理与策略频率均为 62.5 Hz。Zhang 的 100/10 Hz 配置不适用于本任务。
- 终止：静态 LiDAR 或动态障碍碰撞、高度越界、非有限状态；超时为截断。首次进入目标 0.5 m 范围只记录成功事件，回合仍按原规则运行。

控制器、电机配平、共享场景和课程已验证；本次无需重新设计 CTBR 或替换 RotorGroup。原迁移约束见 [NavRL 迁移决策](../adr/0001-port-navrl-with-original-task-semantics.md)。

## 2. 世界模型与 Replay

**状态。** 建议从 18 维刚体状态开始，补充现有 RotorGroup 的 4 维电机 `throttle` 状态，组成 22 维学习状态：

\[
x_t=[p_w(3),\,v_w(3),\,R_{wb}(9),\,\omega_b(3),\,h_{\mathrm{rotor}}(4)].
\]

`root_state()` 提供世界系角速度，须计算 `ω_b=R_wbᵀω_w`。世界坐标直接使用共享场景坐标，不减去并行环境原点。Actor 继续使用原版 202 维观测；电机状态只供世界模型使用。

**状态转移。** 世界模型学习一个策略步内完整的 Lee 控制、RotorGroup 和 PhysX 转移，以执行后的 3 维速度命令为条件；拟合真实 Replay 的多步转移。想象展开从 Replay 状态出发，不能采用 Zhang 的逐步 PhysX 状态对齐。

**观测。** 下一步 202 维观测按原接口组成：

| 部分 | 生成方式 |
| --- | --- |
| 导航状态 8 维 | 用预测位置、速度和回合目标重算 |
| 静态 LiDAR 144 维 | 学习观测预测头；保持 `1×36×4` 顺序、4 m 截断及 `4 - distance` 约定 |
| 动态障碍 50 维 | 用预测无人机状态与动态物体位置、速度和尺寸，按原最近 5 个规则重算 |

**动态场景。** Replay 按策略步保存一份全局障碍状态和活动物体编号，避免每架无人机重复保存 120 个对象。想象时先以当前速度外推短时障碍位置，并对照 `DynamicObstacleMotion` 的实际轨迹。该运动器每 2 s 重采样速度，也会更换到达的目标；若外推误差影响避障，应增加对应的状态更新，不能把动态障碍固定在初始位置。

**回合边界。** `extras["transition"]` 已保存重置前的机体状态和事件。需继续补充重置前的 LiDAR、RotorGroup 状态及障碍快照。Replay 保留首次终止转移，屏蔽其后跨回合的序列。模型留出集记录 1、5、10、32 步的状态和 LiDAR 预测误差。

## 3. 碰撞后想象状态与 Critic

上一轮 ARL 训练发现：世界模型在碰撞后继续外推，异常状态和 Critic 尾值会污染有效轨迹的价值目标。NavRL 应复用以下处理。

1. **对齐真实判定。** 静态碰撞为最近 LiDAR 距离小于 0.3 m；动态碰撞沿用 `navigation_terms()` 的水平半径和竖直高度阈值，各加 0.3 m。边界高度为 0.2–4.0 m。动态物体当前由任务几何判定碰撞，并非 PhysX 接触传感器。
2. **构造可微失败代理。** 在上述真实边界附近，使用连续净空与 sigmoid 计算 `p_fail`。动态长方体和圆柱体必须对齐现有判定，不能直接复用 ARL 的球体–盒体碰撞半径。
3. **吸收终止。** 首次预测碰撞或越界后停止该样本的模型、奖励和 Critic 展开。吸收状态价值置零；首次失败步保留软失败梯度。可以用停止梯度的几何阈值作为前向终止掩码。
4. **隔离 TD(λ) 目标。** 只回归可达状态；终止步不再 bootstrap。使用进入各状态前的累计存活率加权 Critic 平方误差，防止接近失败边界的尾部误差主导更新。真实超时按截断处理。
5. **验证。** 将终止后的假想状态、奖励和价值改为极大值，Actor/Critic 更新应保持不变；同时检查首次失败步仍可向 Actor 传递避障梯度。

NavRL 原奖励不含 ARL 版本的固定 `-5` 碰撞成本，因此不直接复制该数值。若加入失败成本，真实与想象奖励必须采用相同权重。首次安全到达目标不触发吸收终止。

## 4. Actor、Critic 与奖励

**Actor。** 复用 `NavRLEncoder` 和 `BetaHeads`。数据采集时可添加探索噪声，Replay 保存实际执行动作；想象时采用可微的 Beta 分布均值：

\[
a_t=4\frac{\alpha_t}{\alpha_t+\beta_t}-2.
\]

策略动作仍为 3 维目标速度。Actor 更新时冻结世界模型与 Critic 参数，但保留输入梯度；Critic 用固定的想象 TD(λ) 目标训练。复用共享编码器时，必须明确 Actor/Critic 的梯度和优化器归属，避免共享参数重复更新。

**真实与想象奖励。** 优先复用 `task_logic.navigation_terms()` 的目标方向速度、存活常数、静态/动态对数距离、速度变化和高度惩罚。想象奖励使用预测状态和观测计算相同任务项，保留原版的**每策略步奖励**计量方式，避免额外乘一次 `dt`。

需要更早的避障梯度时，可在独立 MBRL 任务中对真实和想象同时加入：

\[
r_{\mathrm{obs}}=-w_{\mathrm{obs}}\big[\max(0,d_{\mathrm{safe}}-d_{\mathrm{clear}})\big]^2.
\]

静态几何最近点可参考 `geometry.py`，但几何选择应停止梯度，净空对查询位置保留梯度。参数 `d_safe` 和 `w_obs` 应根据 Hummingbird 及 NavRL 原碰撞边界设定，不直接沿用 ARL 数值。

控制平稳项适用 `\|a_t-a_{t-1}\|^2`，其中 `a` 是归一化 3 维速度命令；可另记录命令幅值。当前方案无需 CTBR 的 `(c-g)^2` 正则。若未来换成 4 维 CTBR，应独立注册任务并重新核验控制器。

Critic 尾项只加入想象回报目标，不作为真实单步奖励。原 NavRL PPO 奖励保持原样；若比较 PPO 与 MBRL 的算法差异，两者需要使用一致的任务奖励，或明确标记新增净空项带来的奖励差异。

## 5. 训练配置与验收

| 项目 | 初始方案 |
| --- | --- |
| 真实环境 | `NavRLEnv` 的 PhysX 控制链，62.5 Hz |
| 模型拟合窗口 | `k=8` 个策略步，即 0.128 s |
| 想象展开 | `H=32` 个策略步，即 0.512 s |
| 折扣与 TD(λ) | `γ=0.99`、`λ=0.95` |
| 优化 | Actor/模型/Critic 用 Adam；初始学习率均为 `2e-4` |
| 梯度控制 | 全局范数裁剪 1.0；Actor 再做逐元素 0.1 裁剪 |
| 环境数量 | 先以 16/64 环境检查，再进行 1024 环境训练 |
| 课程 | 350 个静态障碍；动态障碍 60→80→100→120 |
| 训练验收 | 100 动态障碍阶段首次安全到达率约 80% |

`k`、`H`、折扣、学习率和裁剪值参考 SuperMimic 论文 Appendix D/Table A.5，是**待在 NavRL 中验证的初值**。并行 batch、Replay 容量和模型网络宽度按实际显存与留出误差确定。

正式训练遵循 [训练课程与验收](../TRAINING_CURRICULUM.md)：从随机初始化，不设更新上限；每次累计至少 1024 个自然结束回合后统计。当前阶段成功率**超过** 80% 才晋级；100 障碍阶段成功率**达到** 80% 即满足验收指标，保存 `checkpoint_best_100.pt`，随后继续 120 阶段。成功事件为碰撞前首次进入目标 0.5 m；记录首次到达率、碰撞率、越界率、超时率、到达时间、训练回报和各奖励项。无需新增独立评测环境。

执行顺序：真实转移采集及控制链检查 → 世界模型拟合与留出误差 → 真实/想象奖励一致性及吸收终止测试 → 小规模 BPTT 训练 → 1024 环境课程训练。检查点保存模型、Actor、Critic、优化器、归一化、课程和随机数状态；恢复训练时重建 Replay。
