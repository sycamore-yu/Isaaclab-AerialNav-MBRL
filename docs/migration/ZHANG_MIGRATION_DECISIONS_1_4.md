# Zhang 可微物理训练迁移决策（第 1–4 项）

本文记录此前在 `issaclab-ARL` 项目中确认的四项核心决策，作为本项目 Zhang 训练实现的约束。核心模块与独立训练入口已实现。真实训练验收以对应实验记录为准。检查结果见 [实现与验证状态](../IMPLEMENTATION_STATUS.md)。
本轮实现采用深度相机，保留已批准的损失。物理频率为 100 Hz，策略与相机频率为 10 Hz，`decimation=10`。默认 BPTT 展开为 150 个策略步，即 1500 个仿真步。速度窗口同样按策略步计数。
## 1. PhysX 前向仿真 + 可微质点动力学反向传播

- **前向：**使用 Isaac Lab 3.0 的 PhysX 更新无人机真实位置、速度、姿态及碰撞状态，保留真实控制器、电机和推力响应。
- **反向：**使用 PyTorch 实现的 Zhang 简化可微质点动力学计算梯度，通过 BPTT（通过时间反向传播）优化策略。
- **目的：**保留 PhysX 训练场景的真实状态转移，同时获得可微的训练信号；不对 PhysX 本身直接自动微分。

## 2. 参考 Song 的状态对齐（State Alignment）

每个控制步把可微模型的**前向数值**对齐到 PhysX 测量状态，同时保留可微模型的**反向导数**：

\[
x_{\mathrm{aligned}}=x_{\mathrm{pred}}+\operatorname{detach}(x_{\mathrm{PhysX}}-x_{\mathrm{pred}}).
\]

其中 `detach` 表示停止梯度传播。因此前向计算有 \(x_{\mathrm{aligned}}=x_{\mathrm{PhysX}}\)，但对模型参数求导时仍采用 \(x_{\mathrm{pred}}\) 的梯度。该方案参考 Song 等的 *Learning Quadruped Locomotion Using Differentiable Simulation*。跨回合重置时必须切断旧回合的计算图，避免梯度穿越不同回合。

## 3. 保留 Zhang 的简化质点动力学结构

- 可微状态以位置、线速度、加速度及内部执行器/加速度命令状态为核心，保留 Zhang 风格的推力响应滞后、阻力等模型因素。
- 可微模型用于**梯度近似与轨迹展开的信用分配**；物理世界中的姿态、力矩、电机动力学和实际碰撞仍由 Isaac Lab 的控制链与 PhysX 处理。
- 发生任务重置时，先保存对齐的终止步及其损失计算图，再截断下一回合的动力学与策略历史。按用户最新决定，`continuous` 的碰撞和高度越界均不触发重置，继续推进动力学；仍保留无效状态和 35.2 秒超时重置。首次失败锁存不因之后恢复或到达而覆盖。

## 4. 保留六维网络输出，最终执行三维加速度指令

- **策略网络原始输出：**六维，由三维加速度相关量和三维速度预测量组成，而不是直接输出六维物理控制命令。
- **动作解码：**按照 Zhang 的原始输出排列、航向坐标变换和速度补偿规则，生成**世界坐标系三维加速度**指令 \(a_{\mathrm{cmd}}\in\mathbb{R}^{3}\)。速度估计分支同时参与原始辅助损失。由 PhysX 更新无人机；不把质点模型的预测位置直接写回仿真。

13. 保留速度匹配、避障、碰撞、加速度、Jerk 和速度预测辅助损失。按用户 2026-10-29 的追加决定，新增仅在上下边界附近激活的 C1 平滑高度损失，并按最新决定替换为非饱和 SmoothL1；不恢复原代码的全域目标高度惩罚。默认逐策略步速度匹配，当前对照见 [新机制](../ZHANG_NEW_MECHANISMS_20261029.md)，旧四方案文档仅作为历史记录。这项追加决定替代此前“无额外高度损失”和默认 60 步速度窗口的约束。

14. 碰撞半径与 无人机仿真中的真实几何对齐。同时用于策略半径输入和避障损失，并此次基础上合理调整原 Zhang 的 0.1–0.3 m 随机机体半径。

15. 随机化交给 Isaac Lab Event Manager。保留初始状态、目标和障碍物采样规则。本轮使用两个任务共享的噪声、延迟、控制响应、质量、惯量和推力配置，见 [共享扰动说明](../SIM_TO_REAL_TRAINING.md)。预训练关闭额外扰动，微调开启。已有风、相机标定和推力估计误差不与本轮参数重复叠加。
没有每轴为 ±2 m/s的限制，并使用\(v_{\max}=(0.75+2.5U(0,1))\times3\)作为源代码中目标速度向量对navrl环境的适配，

9. 物理步长为 0.01 秒，策略步长为 0.1 秒，相机与策略同步。此项按 2026-10-29 的本轮请求更新。

10. 默认 `variant=step`，每个策略步计算自身速度与本步执行前目标速度的 SmoothL1 误差，150 步末统一反传。`continuous`、`dcol` 保留窗口速度损失，默认窗口为 20 个策略步（`velocity_window_s=2.0`）；原 60 步可显式配置。窗口不得跨回合，跨更新的窗口前缀停止梯度。`truncated_window` 已取消并移除活动配置，其结果已归档。BPTT 默认 H=150；SHAC 固定短展开、AHAC 同步自适应展开是单独算法对照，定义见 [SHAC/AHAC 适配](SHAC_AHAC_ADAPTATION.md)。

12. 保留 AdamW。预训练学习率默认 \(10^{-3}\)，微调默认 \(5\times10^{-5}\)。余弦调度每 400 次更新循环一次，对应初始 2000 次更新内 5 个周期。训练不设置更新上限。阶段边界加载本次实验的前序检查点，保留网络与优化器。默认全局梯度范数裁剪为 5.0，候选值为 1、3、5。记录裁剪前梯度范数与非有限梯度事件。另记录实际参数范数、AdamW 更新范数及其比值，覆盖全网络、每层和六维输出行。ReduceLROnPlateau 与余弦调度互斥，先作为对照，未证明更好前不替换默认。
保留 Zhang 原始网络。 使用 CNN + GRU，GRU 隐状态为 192 维。即使有速度观测，仍保留网络的速度预测辅助输出。
两环境共用 NavRL 的相机安装角度和视场参数，原始深度分辨率默认 **160×120**；相对原 640×480 标定，像素焦距和主点均除以 4，保持物理焦距与视场。处理顺序仍为原始射线深度、逆深度变换、像素噪声、池化得到 12×16 深度图。Zhang 另外输入 10 维状态特征，包括自身速度、目标速度、机体朝上方向和碰撞半径。每个输出格包含 10×10 个原始像素，网络结构不变；NavRL 原策略仍使用 LiDAR，不改变 202 维策略接口。新训练从随机初始化使用此分辨率，历史实验保留原配置。

## 本轮训练与验收口径

正式训练默认使用 1024 个并行无人机。预训练 S0（300 静态 / 0 动态）从随机初始化开始，不设优化更新次数上限。展开步数与优化更新次数分别记录。任务超时沿用 NavRL 的 35.2 秒，因此 Zhang 为 352 个策略步。

两任务共用五阶段课程：预训练 300/0 → 300/60 → 400/120，微调 300/60 → 400/100，数字依次表示静态/动态障碍数量。预训练关闭额外扰动，微调开启。每阶段训练首次到达率达到 80% 后晋级。按原 NavRL `EpisodeStats` 的频率，累计至少 `num_envs` 个自然结束回合后汇总并清空统计。首次事件按无效状态、碰撞、高度越界、成功、超时的顺序判定。同一步碰撞和到达记为碰撞。成功后锁定首次结果，保持原终止规则。

最终验收要求五个阶段依次通过，并保存高难度扰动环境中的策略。指标包括首次到达率、碰撞率、超时率、高度越界率、无效状态率、成功到达时间和训练回报。完整口径见 [训练课程与验收](../TRAINING_CURRICULUM.md)。

输入延迟和动作延迟分别采样 0–5、0–2 个策略步。物理执行使用官方 `DelayBuffer`；可微历史使用同一延迟选取动作并核对实际执行值。原训练器单步动作队列已移除。关闭新增机制时，环境保留原 Zhang 单步延迟。Jerk 仍由原损失计算，不增加第二项动作差分损失。

Zhang 的动态物体运动、碰撞和首次到达事件按 100 Hz 物理步检查，策略仍为 10 Hz。沿用 NavRL 的碰撞判据；除 `continuous` 忽略碰撞和高度越界终止外，在策略步末执行终止与重置。首次结果按回合锁存最早物理子步事件及时间，碰撞后到达仍记失败；同一子步仍采用上述优先级。`dcol` 还保存本策略步首次碰撞的位置、子步序号及当时动态障碍位置，使碰撞几何梯度对应同一时刻。原 NavRL 的 0.016 秒步进保持不变。

## 2026-10-29 新机制追加决定

运行统计归一化仅变换策略输入，统计 detach，每段展开固定快照并保存到检查点；物理状态和损失仍用原单位。默认关闭，只有对照结果支持后才改变默认。新机制对照采用 dcol，连续方案另行从零重启。

稳定退化恢复由用户明确授权：同阶段稳定报告先建立检查点，持续退化先降学习率，观察后仍退化才恢复。恢复模型、优化器和匹配的归一化/critic 状态，重置环境及全部历史；全局 update、已采样步数、实际训练报告、随机序列和验收事实不回滚。新实验初始权重仍必须随机初始化，不能把旧实验归档模型作为预训练输入。

旧实验冻结点为 f6d5fd4，标签 baseline/zhang-pre-new-mechanisms-20261029；归档见 [记录](../results/zhang_pre_new_mechanisms_archive_20261029.md)。全部新定义见 [新机制](../ZHANG_NEW_MECHANISMS_20261029.md)。
