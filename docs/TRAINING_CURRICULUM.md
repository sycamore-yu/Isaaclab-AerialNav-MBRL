# 训练课程与验收

本轮采用五个阶段，在此前四阶段之前增加无动态障碍的预训练 S0；替换旧的 60→80→100→120 动态障碍课程。最新用户要求重新加入 fresh NavRL/PPO 方法对照，Zhang 的新 truncated 速度模式也沿用同一课程；新运行须由正式启动回执确认。

| 阶段 | 配置名 | 静态障碍 | 动态障碍 | 额外扰动 |
|---|---|---:|---:|---|
| 预训练 S0 | `pretrain_s0` | 300 | 0 | 关闭 |
| 预训练 S1 | `pretrain_s1` | 300 | 60 | 关闭 |
| 预训练 S2 | `pretrain_s2` | 400 | 120 | 关闭 |
| 微调 S1 | `finetune_s1` | 300 | 60 | 开启 |
| 微调 S2 | `finetune_s2` | 400 | 100 | 开启 |

## 晋级条件

每阶段训练首次到达率达到 0.8 后晋级。统计沿用原 NavRL `EpisodeStats` 的频率：累计至少 `num_envs` 个自然结束回合后汇总并清空。正式验收默认使用 1024 个并行无人机且要求至少 1024。显式 `--screening` 允许较小 N 做同课程比较；即使五阶段门槛全部通过，父结果仍为 `acceptance_passed=false`，仅标记 `stage_thresholds_passed=true`。没有独立评测环境，也不添加额外平滑晋级窗口。

每回合只计入一个首次结果。成功指碰撞前进入目标 0.5 m 范围。成功后继续遵循原任务终止条件，在回合自然结束时计数。同一步事件优先级为无效状态、碰撞、高度越界、成功、超时。Zhang 每个物理步检查首次事件。

阶段通过必须由真实训练报告支持。最终验收还要求五个阶段依次完成，微调 S2 使用 400 个静态障碍、100 个动态障碍并开启共享扰动。有限步检查、合成结果和历史策略不用于验收。

## 模型与地图切换

预训练 S0 从随机初始化开始。后续阶段只读取本次实验前一阶段的检查点，保留网络和优化器。静态地形是合并三角网格，因此阶段边界通过重建仿真进程切换地图。传感器、物理碰撞和最近障碍查询随地图一起重建。

每个阶段重置全部回合、循环网络状态、观测历史、动作历史和速度窗口。微调 S1 加载本次预训练 S2 的权重，重新开始低难度课程并开启扰动。正式运行没有更新次数上限；`--max_iterations` 只用于短检查。

同阶段性能恢复按 [分档恢复协议](migration/RECOVERY_LADDER_20261029.md) 执行：三份稳定报告建立5%起、每5个百分点一档的历史，连续退化先减半学习率，再观察三份仍退化才恢复同阶段最高稳定档。首次80%报告仍可晋级，未有三份稳定报告则不能标记stable80。恢复不会倒退累计样本、真实报告或晋级事实；恢复时重置环境、GRU、延迟和速度历史。它不允许加载别的实验或跨阶段的最好模型。

## 指标与参数

记录首次到达率、碰撞率、超时率、高度越界率、无效状态率和成功到达时间。平均 return 按完成回合数加权；每策略步平均 reward 等于同批回合总 return 除以总策略步数，包含终止步奖励。

Zhang 使用独立损失优化，其 NavRL 环境奖励只用于日志对照；NavRL/PPO 则优化原任务奖励。Zhang 保留 100 Hz 物理频率、10 Hz 策略频率和默认 150 策略步 BPTT 展开。`variant_default` 令step使用逐步速度项，continuous/dcol使用20策略步窗口加合格终止短窗（`truncated_window`）；显式`full_window`恢复旧完整窗口行为，不恢复旧同名几何变体。高度项默认`target_exp`，可选`target_huber`与`boundary_huber`；目标高度取当前回合导航目标z。continuous的碰撞与高度越界不重置。SHAC/AHAC 的时域及 bootstrap 是明确算法对照，见 [新机制](ZHANG_NEW_MECHANISMS_20261029.md)。余弦调度周期为 400 次更新，微调默认学习率为 `5e-5`。短窗分母、公平因素及与 PPO 的方法差异见 [新对照规范](ZHANG_TRUNCATED_PPO_CONTROLS_20261029.md)。

共享随机化参数、延迟语义、名义动力学读取及动作一致性要求见 [共享扰动说明](SIM_TO_REAL_TRAINING.md)。旧实现与结果由 Git 基线 `2456a5b` 及原日志保存。
