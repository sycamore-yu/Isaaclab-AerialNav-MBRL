# 平滑终点速度引导

按用户确认，将本机制设为 Zhang 新训练默认值，并将指定四组实验从停止检查点显式迁移。默认选择来自参考曲线的平滑性分析；实际成功率、超调和速度跟踪改善仍需继续训练的完整回合证据。

## 曲线与依据

设目标误差为 e、距离 r=||e||、回合目标速度 v。旧式速度为 min(v,r/1s)，在 r=v·1s 处斜率突变。新式令 R=T·v，默认 T=2s；s=r/R，定义：

```
phi(s) = s + 4s³ - 7s⁴ + 3s⁵
u(r) = v * phi(r/R)    (0 <= r < R)
u(r) = v               (r >= R)
v_ref = u(r) * e/r
```

phi(1)=1，phi'(1)=phi''(1)=0，因此与巡航段二阶连续；phi'(0)=1，中心附近 v_ref≈e/T。实现直接用 e/T 乘多项式，避免中心方向归一化奇点。距离小于 0.5m 时仍继续温和趋近中心，不硬切为零。

理想直线、精确跟踪且通行门控恒为 1 时，减速度峰值为约 0.976668·v²/R，jerk 峰值为约 3.357421·v³/R²。v=6m/s、R=12m 时分别约 2.93m/s²、5.04m/s³；这些是参考轨迹量，不是无人机机动能力保证或实测值。对应距离 12、8、4、2、1、0.5m 时参考速度约为 6、5.185、2.444、1.081、0.512、0.252m/s。

## 只在最终通行段平滑减速

接近半径内，沿当前位置至目标的直线取 128 个点，复用现有完整静态、地面及动态障碍距离查询，减去机体 margin 和半采样间距。对最小剩余净空在 0–0.1m 内用 quintic smoothstep 生成权重 w，最终参考为 `(1-w)*v_linear+w*v_smooth`。目标仍被墙遮挡时回退旧参考，避免单凭欧氏距离在绕行途中提前慢行。

这是采样的通行启发式，不替代原碰撞检测或可微碰撞损失。地图、动态障碍和门控随状态变化，实际参考加速度不受上述理想直线峰值约束。当前 smooth 的训练及推理均依赖环境的完整已知地图距离查询；它改变目标速度特征的含义，不增加状态维度。部署到没有该查询的系统需另行处理，不能直接忽略门控。
