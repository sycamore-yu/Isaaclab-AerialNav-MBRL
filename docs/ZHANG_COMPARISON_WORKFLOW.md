# Zhang 对照开发流程

Zhang 任务按以下顺序迭代：

1. 固定当前默认配置，作为本轮基线。
2. 在当前默认配置上运行候选对照。
3. 根据训练结果选择更好的配置。
4. 将选中的配置提交到 `main`，设为新默认。
5. 在新默认配置上开始下一轮对照。

每轮记录基线提交、候选提交、配置、种子和结果位置。
替换默认时，提交说明记录收益和适用阶段。
后续对照使用新的基线提交。
历史训练的配置、日志和检查点保持完整。

比较依据是相同课程阶段、相近采样量下的自然回合结果。
结果包括成功率、碰撞率、越界率和超时率。
最近多份报告按完成回合数加权。
训练耗时与采样量分别比较。
不同展开长度的更新次数不能直接表示样本效率。

低难度收益与更高难度退步同时出现时，候选配置继续保留为对照。
默认替换由实验结果决定，不因候选已提交或已通过功能检查而替换。
默认替换后，运行中的历史实验保留原配置。
训练启停遵循用户授权，不随默认配置变更自动重启。

本轮配置见 [20 Hz 默认与新五组对照](ZHANG_20HZ_CONTROLS_20261029.md)。
