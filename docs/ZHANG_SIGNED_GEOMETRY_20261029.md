# Zhang 有符号几何修复与八组对照（2026-10-29）

本次修复替代此前无符号 mesh 距离、动态体内部裁剪投影和最近五中心碰撞判据。
当前研究任务仍使用 Isaac Lab 3.0 / PhysX 正向和 PyTorch 代理动力学反向。

## 几何和梯度

- 逻辑碰撞使用半径 0.3m 的无人机球体。完整轴对齐长方体使用三个半边长；圆柱使用半径和有限高度，包括顶底盖与边缘。动态运动不改变物体朝向，与场景生成方式一致。
- 每次查询覆盖全部活动动态障碍，分块选最小距离，仅对选中障碍保留图和不可变位置副本。最近五中心只用于原 NavRL 观测；策略仍为202维，Zhang仍为10维状态和12×16深度。
- 静态距离使用最终实际三角网格，不重建采样长方体，因此保留覆盖写入后地形形状。对 NavRL 无悬垂、向上定向的开放高度场，用向上射线的首个出射面识别内部，距离为负。表面导数使用外法向；内部使用朝最近表面的单位方向；不把开放网格交给封闭体绕数判定。
- 普通避障和普通碰撞损失直接接收标量有符号距离，再减一次训练半径。保留原平方 barrier、softplus 和 detached 接近速度权重。动态体内不再出现“投影点等于查询点”的零向量。
- 长方体中面、圆柱轴线和中心是不可微点，确定性选一个单侧逃逸分支。DCOL长方体/圆柱在中心也选非零逃逸导数；普通位置用解析隐式导数。中心不宣称存在唯一经典梯度。
- DCOL动态项仍为真正共同缩放的 `radius * (alpha - 1)` 代理量，未改称米制SDF；静态分支改为实际mesh有符号净空。多个动态体取各自SDF最小值，内部不宣称等于重叠并集的精确穿透深度。
- PPO和全部Zhang组共享同一几何事件入口。Zhang每个100Hz物理子步检查，策略10Hz；PPO保持原0.016s步进、策略、观测和奖励。PPO在本仓库使用已有RSL-RL迁移实现，已有优化器/ValueNorm等迁移差异没有因本次修复消失。
- continuous继续关闭接触响应，碰撞/高度越界不重置但锁存首次失败；其他Zhang组保留终止转移图后重置。逻辑球体碰撞和PhysX资产接触响应是不同层次。

## 运行与证据

入口：

```bash
.venv/bin/python scripts/run_geometry_comparison.py \
  --output logs/curriculum/zhang_signed_geometry_20261029 --parallel 4
```

入口冻结src/scripts、记录逐文件SHA256和基线差异，再由冻结源码启动八组。
每次运行独立目录；四组同时执行，余组排队；已失败组保留退出码和原日志，不自动重试或遗漏。

原始训练结果在各组的`zhang/<stage>/`或`navrl/<stage>/`；PPO补记实际更新步数供统一汇总，不改优化行为。
