# Zhang 高度优先梯度投影：离线反事实检查（2026-10-29）

## 范围与证据

使用现有 `GradientDiagnostic` 写入的七项损失梯度 Gram 矩阵及实际 AdamW 参数位移，
只读分析四组实验的 **11 次诊断更新**。没有重新训练、没有调用优化器、
没有修改当前损失或运行中的进程。复现命令：

```bash
.venv/bin/python scripts/analyze_zhang_gradient_projection.py
```

机器可读结果：`docs/results/zhang_gradient_projection_counterfactual_20261029.json`。

记 `g_z = ∇L_height`、`g_total = Σ λ_i ∇L_i`、
`g_other = g_total - λ_z g_z`，`G_ij = ∇L_i · ∇L_j`。
用现有 Gram 矩阵即可精确恢复同一训练样本上七项梯度之间的内积，无须存储完整模型梯度。
两种用于对照的原始梯度方向为：

- **非恶化保护**：`g_guard = g_total + max(0, -g_total·g_z / ||g_z||²) g_z`，
  使 `g_z·g_guard ≥ 0`。
- **高度优先投影**：`g_priority = g_total + max(0, -g_other·g_z / ||g_z||²) g_z`，
  使 `g_z·g_priority ≥ λ_z ||g_z||²`，保留明确的一阶高度下降方向。

零高度梯度时不执行投影。每种反事实方向均按当前 `max_grad_norm=5` 做假设性的
**全局裁剪 SGD** 计算。下表中的 `ΔL_z/η` 为假设步长 `η` 很小时的
一阶变化系数；负数表示下降，正数表示上升。
**它不是 AdamW 的替代实际更新，也不是新轨迹上的损失。**

## 关键结果（全参数空间）

| 实验及更新 | cos(碰撞,高度) | 原方向 `ΔL_z/η` | 非恶化投影 | 高度优先投影 | 高度优先附加系数 | 实际 AdamW 一阶 `ΔL_z` |
|---|---:|---:|---:|---:|---:|---:|
| continuous signed，#7 | +1.0000 | -37.0692 | -37.0692 | -37.0692 | 0 | -0.060726 |
| continuous signed，#10 | **-0.9534** | **+6.3625** | 0.0000 | **-1.8298** | +6.6759 | **+0.024429** |
| DCOL step，#7 | -0.1841 | +0.2034 | 0.0000 | -0.0186 | +12.2900 | -0.000873 |
| DCOL step，#10 | -0.4570 | +0.0876 | 0.0000 | -0.0063 | +14.7986 | +0.000565 |
| height×8 continuous，#10 | +1.0000 | -6.4574 | -6.4574 | -6.4574 | 0 | -0.020956 |
| height×5 step，#12 | -0.2086 | -0.2401 | -0.2401 | -0.3144 | +1.1816 | **+0.000556** |

**结论 1：** 在连续展开 #10，原始梯度即使经过范数裁剪，仍是一阶**增加**
高度损失的方向；高度优先投影改为一阶下降。原始实际 AdamW 位移的高度损失
一阶变化也为正，和梯度冲突的诊断一致。

**结论 2：** 当原方向已降低高度损失时，非恶化保护不修改梯度；
高度优先模式仍可能放大高度分量。例如 height×5 #12，其原始方向预测高度下降，
但实际 AdamW 位移预测高度上升，说明**即使投影方向正确，AdamW 动量与逐坐标缩放仍可能改变实际更新方向**。
需要在真正训练消融时监控 `g_z·Δθ_AdamW`。

**结论 3：** 投影存在其他目标代价。在 continuous signed #10，原方向预测碰撞损失
`ΔL_collision/η = -6.497`，高度优先投影后变为 `+0.517`：
高度损失获得保护，但碰撞损失可能在一阶近似下恶化。此处不是无代价的改进。

**结论 4：** 当高度梯度近零或局部逃逸方向错误时，梯度投影不能修复几何信息，
更不能凭空产生左右绕行方向；必须先检查静态障碍距离定义。

## 静态几何源代码与最小反例

当前 `src/isaaclab_navrl/tasks/navigation/geometry.py` 用
`wp.mesh_query_point_no_sign` 取得最近表面点 `q`；
`zhang/losses.py` 使用 `||p-q|| - r`；`zhang/dcol.py` 的
`hybrid_collision_gap` 对静态地形仍使用这个无符号间距，动态凸体才使用 DCOL。

离线 PyTorch 解析反例（**示意的单独盒体，而非实际地形训练数据**）：
矩形障碍 `x ∈ [-1,1], y ∈ [-1,1], z ∈ [0,6]`，无人机半径 `r=0.3`，
无人机中心 `p=(0.8,0,3)` 在障碍内部，最近侧面 `q=(1,0,3)`。

- 旧 `gap = ||p-q||-r = -0.1`，原碰撞损失的 `∂L/∂x ≈ +30.747`，
  **梯度下降会减小 x，把无人机推向障碍内部**。
- 若改为正确的盒体有符号距离，`gap_signed = -0.2-r = -0.5`，
  同一损失的 `∂L/∂x ≈ -32.0`，梯度下降会**增大 x，朝侧面逃出**。
- 在盒体更深处 `p=(0,0,3)`，旧 `gap ≈ +0.7`、碰撞损失约 `1.87e-10`，
  **障碍内部反而几乎没有碰撞惩罚**。盒体中心的正确 SDF 在对称点可能有
  多个合法次梯度，需要结合目标方向/局部规划选择侧向方向。

## 推荐的几何修复（暂未写入训练）

1. **最小修复：沿用实际地形 mesh 最近点查询，但为静态高度场增加可靠的内外判定。**
   地形是单值高度场形成的实体 `z ≤ h(x,y)`。从最终 PhysX 对齐 mesh
   预计算/查询世界坐标高度 `h(x,y)`，用 `z - h(x,y)` 判断内外；
   `signed_distance = sign(z-h(x,y)) * ||p-q_mesh||`，再减无人机半径。
   必须检查竖直崖壁、格点边界、地面和范围外查询。**不能**从独立细网格柱
   直接取最小距离，避免人工内部表面。
2. **同时替换碰撞项与避障项的静态间距。** 当前两项分别来自无符号 `distance`
   和混合 `collision_gap`；只改后者仍会保留错误的避障梯度及 approach 加权。
   需要对真实几何的符号、深度及 `∇_p gap` 做一致性测试。
3. **对高于可飞高度上限的静态障碍，增加侧向可行性。**
   从最终高度场提取在安全飞行高度不可跨越的足迹集合，计算 **XY 平面的有符号距离**
   与侧向法向；在顶部不可通行时额外施加水平余量损失，而不是仅凭三维最短距离
   选择向上。利用左/右绕行候选和前进目标做局部可行性判别，避免仅靠排斥场卡在局部极小值。
4. **后续强实现：** 如果高度场边界符号或网格插值的误差不可接受，离线构建
   由**最终实体占据集合**生成的 3D SDF/ESDF，再用可微三线性插值在线查询；
   避免对重叠盒子和人工内部面简单求最小值。

当前 `pretrain_s0` 为 **300 个静态障碍、0 个动态障碍**。
因此 S0 的 `dcol` 实验并没有动态凸体 DCOL 可微优势，
单靠现有动态 DCOL 无法修复这里的静态梯度。

## 不应外推的结论

- 投影的有效性只在已有诊断的参数梯度上得到**局部一阶**支持；
  既没有新的 AdamW 反事实更新，也没有更高的成功率证据。
- 输出头 `z_head` 与全网络参数空间的 Gram 不同；不能只对 `z_head`
  计算投影就声称全模型高度安全。机器可读文件保留 `all/trunk/z_head` 三套结果。
- 静态 SDF 修复应作为独立消融；不要同时修改策略架构、学习率和课程，
  否则无法识别收益来自几何还是优化器。
