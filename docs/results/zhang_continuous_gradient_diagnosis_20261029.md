高度损失为 `SmoothL1((relu(0.7-z)+relu(z-3.5))/0.5, 0)`，其中距离单位为 m。下界激活比例统计 `z < 0.7 m`，上界激活比例统计 `z > 3.5 m`，与任务实际高度边界 `[0.2, 4.0] m` 有区别。下文高度使用 m，速度使用 m/s，执行加速度命令使用 m/s²，比例使用百分数。损失和梯度投影是该归一化目标及参数坐标下的量，不能解释为米、速度或飞行成功率。

定义 `g_h = ∇L_height`、`g = Σ c_i ∇L_i`、`Δθ = θ_after − θ_before`：

- `g_h · g > 0`：沿原始总梯度的负方向更新，一阶降低当前轨迹上的高度损失。
- `g_h · Δθ < 0`：实际 AdamW 位移一阶降低当前轨迹上的高度损失。
- `g · Δθ < 0`：实际位移一阶降低当前总目标。

这里的“一阶”均以该次展开的计算图和更新前参数为基点，不是重新执行 PhysX 后的实测损失变化。梯度诊断定义见 [diagnostics.py](../../src/isaaclab_navrl/zhang/diagnostics.py)，损失定义见 [losses.py](../../src/isaaclab_navrl/zhang/losses.py)。

## 4. 高度系数的局部反事实

当前高度系数为 1。仅改变该系数、保持同一计算图的分项梯度不变时，

```text
g_h · g(c) = g_h · g(1) + (c - 1) ||g_h||²
c_critical = max(0, -sum_{i != h}(c_i * g_h · g_i) / ||g_h||²)
```

U10 全网 `||g_h||² = 2.511599116`，临界系数 **6.675950**；z_head 临界系数 **6.733076**。

| 高度系数 | 全网 `g_h · g(c)` | z_head `g_h · g(c)` |
| --- | ---: | ---: |
| 1（实际基线） | -14.255710 | -14.150834 |
| 5（反事实） | **-4.209313** | **-4.277717** |
| 8（反事实） | **3.325484** | **3.127121** |
| 10（反事实） | 8.348682 | 8.063680 |

因此系数 5 在该局部状态上仍冲突，系数 8 可以翻转原始方向。**该阈值不是 clip + AdamW 的实际位移阈值**：Gram 矩阵不包含逐坐标预条件和动量，不能据此保证 `g_h · Δθ < 0`，也不能保证新轨迹高度下降或成功率提高。

在相同参数、梯度和优化器状态下，只缩小正学习率会等比例缩小本步位移，不能翻转其高度投影。fresh 低学习率会改变之后的全部轨迹，因此仍有独立的长期检验价值，不能被这条局部结论排除。

### 预测、反证与决策

1. **主要机制预测：** 当新组出现与基线 U10 相似的上下界混合状态时，提高高度权重应减弱原始目标冲突，并使实际 `g_h · Δθ` 更趋向负值；随后应减少上界激活和持续上升。需同时报告下界激活，避免以更严重的下坠换取上界比例下降。
2. **若原始内积转正、实际高度投影仍为正：** 原始权重调整未保证真实优化器步纠正高度；下一步再针对动量、预条件或步幅设计对照，不能宣布高度问题已解决。
3. **若两类投影均改善而轨迹仍失控：** 本轮局部解释不足以覆盖闭环行为，应检查跨更新状态分布及动作响应，不能仅以梯度符号判定训练有效。
4. **若新组没有重现基线的失控状态：** 用同预算的原始高度/碰撞/速度损失、上下界激活比例、垂直速度及自然回合统计描述改进，不能要求不同轨迹的 Gram 数值逐项相同，也不能据此声称已复现反事实计算。
5. **训练效果仍按原协议判断：** 使用自然报告的 episode 加权成功率、碰撞/边界/超时构成，以及完整课程的既有 80% 标准。总加权 loss 因高度系数变化而不可直接横比；单个局部投影、单峰成功率或 S0 改善均不等于最终验收。

可选的独立第二组是 fresh `lr=2.5e-4`、高度系数仍为 1，检验更小初始步幅是否避免地下阶段；不要与 height=8 同时修改后称为单因素试验。

## 统计与可迁移结论的限制

本记录只有一个种子、三个选定更新，全部处于 S0；时间步和并行环境中的状态并非独立统计样本。诊断中的 rollout 在当次更新前采集，实际位移在更新后测量，不能把它们拼成更新后真实环境重放。七项梯度份额仅描述参数空间，不是物理运动因果份额。该 continuous 结论不能直接外推到碰撞即重置的 dcol、SHAC 或 AHAC。

自然训练报告用于课程与验收；本文件没有提供独立固定策略评测结果。记录包含额外梯度诊断时间，且训练共享 GPU，不能由本次墙钟时间作独占训练速度结论。height=8 的启动及验收状态需由后续真实 receipt 与日志更新。
