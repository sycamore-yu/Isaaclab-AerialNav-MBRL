# 共享扰动与观测时间

默认配置位于 `tasks/navigation/randomization.py` 的 `SimToRealCfg`。延迟用秒保存，运行时转换为策略时钟上的整数步。边界之间只采样可表示的时刻，不超过配置上限。以下为 20 Hz 的默认值。

| 机制 | 默认参数 | 作用位置 |
|---|---|---|
| 深度输入延迟 | 0、50、100 ms | Zhang 已收到的深度帧及该帧采集位姿 |
| 动作延迟 | 0、50 ms | 控制器前的命令 |
| 位置噪声 | 每轴标准差 0.02 m | 位姿估计 |
| 速度噪声 | 每轴标准差 0.05 m/s | 速度估计 |
| 姿态噪声 | 旋转向量各轴标准差 1° | 姿态估计 |
| LiDAR 噪声 | 距离标准差 0.02 m | NavRL 策略扫描 |
| 深度噪声 | 逆深度域标准差 0.02 | 池化前的像素测量 |
| 控制响应 | 名义值乘 U(0.6,1.4) | 速度增益或加速度响应速率 |
| 质量、惯量、推力系数 | 各自乘 U(0.9,1.1) | PhysX 与执行器 |

`input_delay_range_s=(0.0,0.1)`、`action_delay_range_s=(0.0,0.05)` 替代旧的步数配置字段。动作延迟按用户要求由 0–40 ms 取为 20 Hz 时钟可表示的 0/50 ms。PhysX、策略和深度相机仍是 20 Hz。其他频率记录其实际整数步范围；低于一个策略步的正延迟无法表达。

NavRL/PPO 保留整组 202 维观测延迟。Zhang 使用以下观测时间约定。

## Zhang 深度补偿

延迟缓存同时保存深度测量、采集位姿和采样时刻。缓存不足时使用本回合最早帧，报告实际帧龄；局部 reset 不读取上一回合的数据。同一策略步重复读取不会再次采样或推进缓存。

策略使用当前机载位姿/速度估计，以及已经收到的旧深度。旧深度先反投影，再通过采集位姿与当前位姿之间的变换投到当前相机。z-buffer 选择最近点，再生成原有 12×16 逆深度特征。未覆盖的像素不从当前相机或场景几何补齐。完全没有测量的池化单元用 −1 表示未知；已观测远距离的正常特征约为 −0.475。

该处理假设存在更新及时的机载状态估计。仿真以带配置噪声的自身真值模拟该估计器，没有运行真实 VIO。补偿只使用自身位姿估计、相机标定和已收到的深度。补偿不读取障碍物真值速度、物体 ID 或视野外表面。未知的障碍运动及新显露区域无法恢复。因此本功能消除的是旧相机坐标系造成的空间偏差，不是消除全部信息延迟。

输出仍为单通道深度和 10 维自身/目标状态，CNN+GRU 结构不变。动作解码采用同一份机载姿态估计。奖励和可微动力学沿用训练用的真实状态；这些状态不新增为 actor 输入。

`Observation/depth_age_s` 记录收到的图像平均帧龄；`Observation/depth_known_fraction` 记录重投影后的像素覆盖比例。帧龄不会因重投影被清零。每份配置与检查点记录 `observation_contract=delayed_depth_current_odometry_ego_reprojection_v1`。

## 动作与恢复

物理执行继续使用 Isaac Lab `DelayBuffer`。BPTT 不可变历史选取同一延迟动作，`executed_action_max_error` 必须为 0。关闭额外扰动时保留 Zhang 原单步动作延迟，在 20 Hz 下也是 50 ms。

旧实验保留冻结源码、日志和检查点。新默认不用于悄悄恢复旧训练；阶段恢复会检查观测约定。不含额外观测延迟的旧权重评测仍可使用原输入形状。正式恢复旧实验应使用该实验的冻结源码。

## 训练与对照

固定 finetune S1 对照继续直接训练。当前没有证据证明课程是达到目标成功率的必要条件。多阶段训练入口仍可用，阶段及验收规则见 [训练课程](TRAINING_CURRICULUM.md)。比较课程时，墙钟必须包含预训练成本，并在相同最终难度统计完整回合结果。

本次不修改奖励系数、网络主干、SHAC 配方或已运行的对照。深度＋运动事件仅作为 [独立 demo](DEPTH_EVENTS_DEMO_20261030.md)，未启用为训练默认。
